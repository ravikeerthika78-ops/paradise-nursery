# Paradise Nursery

Paradise Nursery is a responsive online plant nursery web application designed for browsing and purchasing indoor and outdoor plants.

## Project Name
Paradise Nursery

## Description
This project provides a simple and user-friendly interface for customers to explore a wide variety of plants, view product details, and manage their shopping cart efficiently.

## Features
- Browse indoor and outdoor plants
- View plant details
- Add and remove items from the shopping cart
- Responsive and easy-to-use interface

## Technologies Used
- HTML
- CSS
- JavaScript
- React
