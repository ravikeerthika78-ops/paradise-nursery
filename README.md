# 🌿 Paradise Nursery - Plant Shopping Application

## 📌 Project Overview
Paradise Nursery is a modern React-based e-commerce web application designed for plant lovers. It allows users to browse a wide variety of indoor and outdoor plants, add products to their shopping cart, update quantities, and manage their purchases through a simple and responsive interface.

---

## 🚀 Features

- Beautiful landing page with background image
- Product listing categorized by plant type
- Add plants to shopping cart
- Increase or decrease product quantity
- Remove products from cart
- Dynamic cart total calculation
- Responsive design for desktop and mobile
- State management using Redux Toolkit
- Modern React functional components

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Paradise-Nursery.git
```

Go to the project folder

```bash
cd Paradise-Nursery
```

Install dependencies

```bash
npm install
```

Start the application

```bash
npm run dev
```
